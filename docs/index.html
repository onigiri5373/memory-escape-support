おぼえて、
フラッグへ！

「トリオは無事にフラッグに辿り着けるのか」（英語名 Can Torio Make It to the Flag?）は、数秒だけ表示されるばくだんの配置を記憶して、見えなくなった盤面をひよこのトリオと一緒にフラッグまで進むパズルゲームです。旧名は「メモリーエスケープ」です。

SUPPORT

サポート

あそびかた

ばくだんの位置を覚えたら、画面下のあしあとボタンでトリオを1マスずつ動かし、フラッグのマスを目指してください。

記録について

ステージの進行、星、ハイスコアはこの端末内だけに保存されます。アプリを削除すると、端末内の記録は削除される場合があります。ブラウザ版（onigiriboys.com）の記録は、そのブラウザの中だけに保存されます。

動作環境

iOS 17 以降に対応しています。ログイン、アカウント作成、インターネット接続は必要ありません。

収集する情報

「トリオは無事にフラッグに辿り着けるのか」（iPhone 版・ブラウザ版）は、個人情報、利用状況、端末識別子、位置情報、連絡先、写真その他のデータを収集しません。広告、解析、トラッキングのための SDK やスクリプトも使用しません。

端末内の記録

ステージの進行状況、星の数、ハイスコアは、ゲームを動作させるために端末内（ブラウザ版ではそのブラウザの保存領域）へ保存されます。これらの記録が開発者その他の第三者へ送信されることはありません。

第三者への共有

当アプリは情報を収集しないため、第三者への販売、共有、広告利用を行いません。アカウント作成やログインもありません。

ポリシーの変更

機能の追加などにより本ポリシーを変更する場合は、このページに最新の内容と制定日を掲載します。
